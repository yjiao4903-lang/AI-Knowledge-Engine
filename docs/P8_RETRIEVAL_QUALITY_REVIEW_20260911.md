## 背景（事实）

- 语料从 **189 篇 / 9,780 chunk** 扩至 **3,566 篇 / ~296,385 chunk（18.9× / 30.3×）**；四方计数一致 `consistent: true`。
- 同一套 50 题 Golden：`hybrid_rerank` Hit@5 **0.82** / MRR 0.640 / NDCG 0.678，旧门线 0.90 / 0.75 / 0.80 → `gate_pass = false`。
- 失败 9/50：LOW_DENSE_RANK×5、NO_RECALL×2、BAD_FUSION×1、BEST_ARM_FAIL×1。

## 本包已完成的关键结论

1. **瓶颈是语料竞争**：仅将检索域从全库收窄到旗舰归档 187 篇，Hit@5 0.82→**0.90**、MRR 0.640→0.752、NDCG 0.678→0.789、NO_RECALL 2→0。
2. **候选深度/召回广度均非瓶颈**：扩 fused_k 无收益且 p95 +79%（触发停止规则）；扩 dense/terms 到 100 把失败题拉入候选池但融合名次 117/195，够不到重排。
3. **单参数杠杆最多 +0.02 Hit@5**；只有语料分层能到 0.90 ⇒ 指向 **Corpus Routing（分层检索）**。
4. **语料治理发现**：外资研报 tier 占全库 74% chunk，其 99.9% 落在占位标题下（`元信息` 覆盖 155,616 chunks）——根因是抽取阶段丢失标题。
5. **引擎/流程缺陷**：reconcile 非确定性重解析 `M04/M09/_最终报告`（M09 45↔77 chunks），旧金标间歇解析失败、计数抖动。
