# 无模型默认工作台 + 显式 AI 实验室交互规格

版本：v1.0  
日期：2026-09-01  
目标：默认工作台完全不调用大模型；需要 AI 时由用户显式进入实验室。检索降级不得被包装成 AI 或“智能检索”成功。

## 1. 产品决策

### 默认行为

用户打开应用后进入“工作台”，不启动模型、不发起模型请求、不自动生成摘要或建议。工作台只处理可复核的本地结构化数据、归档文件和固定 evidence。

### 显式行为

AI 实验室是独立入口。只有用户点击进入、选择任务并确认运行后，才允许发起 AI/外部 Worker 操作。离开实验室后不得在后台继续运行模型任务；正在运行的任务必须显示并允许用户停止或返回任务状态。

### 知识变更原则

任何 AI 输出默认是候选材料。不得自动晋升为事实、Cognition、Proposal 或正式知识；不得自动写入生产数据。需要沉淀时必须经过 proposal-first 的预览、用户确认、审计和可回滚流程。

## 2. 默认工作台能力

### 2.1 关键词检索

- 支持标题、对象文本、来源名、task ID、evidence ref 的关键词检索。
- 默认是精确/文本匹配，不暗示语义理解。
- 显示命中数、当前过滤条件和结果来源。
- Qdrant 不可用时仍可使用不依赖向量的关键词和字段筛选；不得显示“智能检索成功”。

### 2.2 字段筛选

至少支持：

- task ID / run 名；
- task type；
- `epistemic_state`：`supported`、`inference`、`uncertain`、`partial`（如产品层保留）；
- source/evidence 文件；
- 时间范围；
- 是否含 evidence refs、是否存在 tension；
- 归档状态和运行状态。

筛选条件必须可见、可清除、可复制为 URL 或查询状态；筛选不触发模型调用。

### 2.3 证据阅读

用户可从 claim/tension 打开：

- 原文主张；
- `epistemic_state`；
- evidence refs；
- 对应 evidence 片段；
- 来源、时间、口径和审计理由；
- 是否为预测、估算、目标/情景或 inference。

界面必须区分“证据原文”“系统状态”“人工/Worker 推断”。引用缺失时显示缺失，不用模型补写。

### 2.4 TaskPack 归档

- 浏览 runs、任务数量、任务状态和归档时间；
- 查看任务详情、摘要、claims/tensions 数量和结果文件状态；
- 下载或打开归档结果；
- 归档读取不等于向量检索，页面须显示数据来源为“TaskPack 文件归档”。

### 2.5 Proposal-first 状态

工作台可以显示 `candidate`、`pending_review`、`approved`、`rejected`、`archived` 等状态，但默认只能查看和筛选。`supported` 不等于已批准知识；`inference`、`uncertain`、`partial` 不得自动变成事实。

## 3. AI 实验室

### 3.1 进入与退出

主导航提供独立入口“AI 实验室”，不得把模型按钮混入默认搜索框。

进入时显示确认页：

> 你将进入 AI 实验室。此处可能调用模型或外部 Worker，输出仅为候选结果，不会自动写入 Cognition、Proposal 或正式知识。

用户必须选择任务/TaskPack、允许的 evidence 范围和运行操作后才能开始。

退出时：

- 未运行：直接返回工作台；
- 运行中：提示“任务仍在运行”，提供停止、后台查看状态、继续留在实验室三个明确选项；
- 已完成：结果保留在实验室/TaskPack 回包区，返回工作台不会自动导入。

### 3.2 实验室结果展示

每条输出必须同时显示：来源类型、task/run、evidence refs、`epistemic_state`、生成时间、模型/Worker 标识（如有）和“尚未批准”状态。

显示层级：

1. 证据支持的事实；
2. inference/推断；
3. uncertain/预测、估算、目标或情景；
4. tension/未化解张力；
5. 缺失证据、冲突和待人工判断。

### 3.3 禁止行为

- 默认页、搜索、筛选、打开归档时自动调用模型；
- 用模型生成的摘要覆盖 evidence 原文；
- 把 `inference`、`uncertain`、`partial` 自动改成 `supported`；
- 把未来预测、估算、市场份额、TAM、情景目标标成已验证事实；
- 没有直接证据时输出强因果并标 supported；
- AI 结果自动写入 Cognition、Proposal、正式知识或生产数据；
- Qdrant 不可用时把关键词结果、文件读取或空结果描述为语义检索成功。

## 4. 导航与页面规格

### 一级导航

`工作台`｜`TaskPack 归档`｜`AI 实验室`｜`审批/Proposal`

- 工作台：默认入口，无模型。
- TaskPack 归档：文件和运行结果只读浏览，无模型。
- AI 实验室：显式模型/Worker 操作区。
- 审批/Proposal：查看候选、预览变更、确认或拒绝；不因结果生成而自动批准。

### 页面级行为

| 页面 | 默认行为 | 必须显示 | 禁止 |
|---|---|---|---|
| 工作台 | 本地关键词/字段筛选 | 数据来源、过滤条件、Qdrant 状态 | 自动模型摘要/语义召回伪装 |
| TaskPack 归档 | 读取 run/task 文件 | run、task 数、结果状态、来源 | 自动导入知识 |
| 证据详情 | 展示原文和 refs | 状态、口径、时间、审计理由 | 用模型补全缺失证据 |
| AI 实验室 | 用户确认后运行 | 模型/Worker、输入范围、候选状态 | 后台隐式运行/自动晋升 |
| Proposal/审批 | 预览、确认、拒绝 | diff、provenance、回滚信息 | 自动确认或静默写入 |

## 5. 空态和错误态文案

### 工作台

- 无结果：`未找到匹配项。请调整关键词或筛选条件；当前未调用模型。`
- 无归档：`暂无 TaskPack 归档。你可以在 AI 实验室完成任务后回传结果，再返回此处查看。`
- Qdrant 降级：`向量检索当前不可用。关键词检索、字段筛选和归档读取仍可用；以下结果不代表语义检索成功。`

### AI 实验室

- 未选择任务：`请选择 TaskPack 或任务后开始。尚未调用模型。`
- 运行确认：`即将调用模型/外部 Worker。输出为候选结果，不会自动写入知识库。`
- 运行失败：`AI 实验未完成。请查看失败原因和回包状态；未产生自动知识变更。`
- 待人工：`结果已生成，仍需人工核对证据、认识状态和来源口径。`

### 审批页

- 候选：`这是候选材料，不是已批准事实。`
- 含不确定性：`该对象包含预测、估算、推断或情景口径，请在确认前保留限定词。`
- 未授权写入：`尚未获得写入授权；当前仅可预览，不能提交变更。`

## 6. 可验收标准

### 必过项

1. 冷启动并打开工作台不会产生模型/Worker 调用记录。
2. 关键词、字段筛选、证据阅读和 TaskPack 归档读取在无 Qdrant 时仍可用。
3. 无 Qdrant 时 dense/hybrid 检索和索引操作明确失败或显示降级，不返回“检索成功”。
4. AI 实验室必须经显式入口和确认后才运行；退出后无隐式后台模型任务。
5. 每条 AI 输出展示来源、evidence refs、epistemic state、时间和候选状态。
6. 所有 claims/tensions 的状态合法且可见；预测/估算/目标/情景不得标 supported。
7. 没有直接证据的因果不得标 supported。
8. AI 结果不会自动写入 Cognition、Proposal 或正式知识。
9. Proposal/审批必须提供预览、用户确认、审计记录和可回滚路径。
10. 空态和错误态文案能区分“无模型工作台”“AI 实验失败”“Qdrant 检索降级”。

### 验收记录要求

验收报告必须分别记录：默认工作台、TaskPack 归档、AI 实验室、审批/Proposal 四个页面/模块；不得用静态文档或 API 成功代替 UI 验证。未实际运行或未实际打开的层面标记为 `NOT VERIFIED`。

## 7. 范围外

- 本规格不规定模型选型、提示词工程或外部 Worker 内部实现；
- 不设计 Qdrant 的索引参数、向量模型或迁移方案；
- 不授权 Cognition/Proposal 数据写入；
- 不把“无模型默认工作台”扩展为离线全文搜索产品的全部能力；
- 不替代 Task10 的机器 Gate、人工 entailment 审核或正式导入审批。
